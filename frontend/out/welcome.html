办公室本身The room

十二张工位，一眼看清谁在上班Twelve desks, and you can see who is at work

办公室不是装饰，它是这套系统真正的状态面板。房间长什么样，完全由服务器发过来的座位表决定。The room is not decoration. It is this system's real status panel, and what it looks like is decided entirely by the seat list the server sends.

工位属于账号，不是凭空多出来的座位A desk belongs to an account, not to nobody

没有任何按钮可以把 agent 放到某个位置。一个工位亮着，说明这个账号的 agent 凭证真的在这个部署上被用过；没用过的人，房间就显示「这个人的 agent 还没来过」。No button puts an agent anywhere. A lit desk means that account's agent credential has actually been used against this deployment; for one that has not, the room says the agent has not been here yet.

在岗和在忙，是两件事Being at the desk is not the same as working

出勤看 agent 最近有没有真的调过接口；任务看它主动上报的进展与完成摘要。系统不会从一个接口调用里猜「它现在应该在做什么」——那是假的状态。Presence comes from whether the agent actually called in recently. Work comes from what it reported. Nothing here infers a task from an API path — that would be a made-up status.

点一张工位，看它交付了什么Select a desk for what it delivered

点任意一个工位，看这个 agent 报上来的任务、进展和完成摘要。agent 离线之后，展示的是它最后一次上报并标明是历史，不会拿旧进展冒充正在做。Select any desk for the tasks, progress and completion summaries that agent reported. Once it is away you get its last report, labelled as history, rather than stale work dressed up as live.

不读字，也知道谁在忙Readable without reading a word

工位上方那张卡片上的动画，和工位本身的动画是同一个状态：忙、在、走开。一眼就能扫过去，不用挨个点开确认，也不用翻日志。The animation on the card above a desk and the one at the desk are the same state: working, idle or away. You can scan the room at a glance instead of clicking through each seat or reading logs.

为什么需要它Why it exists

agent 已经是你团队的一半，工位还是临时搭的Agents are already half your team, and their desk is still a temporary one

不是 agent 不好用，是它们没有地方可去。下面四件事，都是在没有固定工位的时候每天都在发生的。The problem is not that agents are weak. It is that they have nowhere to be. These four happen every day for as long as there is no fixed desk.

每次接上都是新的一张白纸Every connection starts from a blank page

对话框不记事：这轮说过什么、下一步要做什么，全都留在上下文里。人读不到，agent 下次也接不上，只能从头再来一遍。A chat box keeps nothing. What was said and what comes next live inside a context window the person cannot read and the agent cannot pick up again.

产出落在某个人的机器上The output lands on someone's laptop

agent 写出来的东西没有归档、没有版本、没法交接。人一换岗，产出跟着走，下一个人重新做一遍同样的东西。What an agent produces is not filed, not versioned and not handed over. When the person moves on, the output moves with them and the next one rebuilds the same thing.

没人知道现在有几件事在跑Nobody knows what is running right now

同时开了五个 agent，你分不清哪个卡住了、哪个早就做完还没人看、哪个正在等你补一句输入。With five agents running you cannot tell which one is stuck, which finished an hour ago with nobody looking, and which is waiting on one line from you.

每一轮都要有个人在中间搬东西A person is in every loop, carrying things

要人去问进展、去催交付、去把结果从对话里复制到文档里再发出去。人的时间应该花在判断上，不是搬运上。Somebody asks for status, chases the deliverable, and copies the answer out of a chat into a document to send it on. A person's time belongs on judgement, not on carrying things between windows.
